# 快速开始示例

用户可上传：
- 初始问卷；
- 理论框架/开题报告；
- 已有成熟量表或参考文献；
- 目标人群与分层变量说明。

然后提出：

> 请使用 AI问卷硅样本预调研 工作流，先审查我的初始问卷，不要立即生成数据。先给出构念—维度—题项映射、题项语言问题、维度边界问题、硅样本分层设计和第一轮分析方案，等我确认后再进入模拟。

第一轮后可继续：

> 按固定分层生成第二轮独立硅样本，保持探索/验证分组不变，对修改后的版本重新做项目分析、平行分析、PAF+Oblimin EFA、CFA、α/ω、CR/AVE、Fornell–Larcker、HTMT，并与上一版比较。所有“未接触/无法判断”按缺失处理，结构分析使用明确的完整案例样本。
