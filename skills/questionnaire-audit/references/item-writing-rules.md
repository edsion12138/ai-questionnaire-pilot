# Item writing rules

## Core rule
Each item should primarily measure one interpretable behavior, judgment, state, or belief.

## Preferred properties
- concise sentence;
- common vocabulary for the target population;
- clear task or referent;
- one response process;
- no hidden second condition;
- consistent subject and time frame;
- response scale matches the item stem.

## Common problems
- “我能A并B” when A and B may differ;
- “我熟悉并能熟练使用……” combines knowledge and performance;
- technical vocabulary only some subgroups know;
- “经常/及时/有效” without a defined frame;
- asking ability when the answer actually reflects exposure/opportunity;
- asking multiple settings in one item;
- leading wording that makes one response socially desirable.

## Competence/self-efficacy items
When the construct is competence, prefer an observable-action stem such as “我能……”, and keep the action concrete enough that respondents can recall relevant experience.
