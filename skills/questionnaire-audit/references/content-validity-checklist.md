# Content-validity checklist

For each dimension ask:
1. What is the construct boundary?
2. What must be covered for the dimension to be interpretable?
3. Which items are core versus optional/context-specific?
4. Are there redundant items that differ only lexically?
5. Would deleting a weak item remove a unique content facet?
6. Is any item actually an antecedent, outcome, attitude, or opportunity rather than the target construct?
7. Can all intended subgroups encounter the task described?
8. If “not exposed / cannot judge” is plausible, should that option be available and analyzed as missing rather than a low score?
