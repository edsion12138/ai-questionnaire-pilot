# Missing-data rules

## Default pre-pilot rule
- valid scale responses: as defined by the questionnaire, e.g. 1-5;
- structural non-response such as “not exposed/cannot judge”: missing;
- item descriptives: available valid responses per item;
- multivariable structural analysis: common analysis sample with N reported explicitly.

## Why “not exposed” is special
It can reflect opportunity or curriculum exposure rather than low competence. Coding it as the lowest score changes the construct. Simple mean imputation can also erase meaningful subgroup differences.

## Escalation rule
If complete-case retention is low:
1. inspect item-level missing rates;
2. cross-tab missingness by major/grade/other relevant groups;
3. identify structurally narrow items;
4. consider item revision before sophisticated imputation;
5. for final human CFA, use an estimator/missing-data treatment appropriate to ordinal data and software capabilities if needed.
