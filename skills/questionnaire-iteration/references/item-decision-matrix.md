# Item decision matrix

Recommended columns:

| Field | Purpose |
|---|---|
| Item ID | stable tracking across versions |
| Dimension | theoretical home |
| Valid N / missing rate | applicability and exposure |
| CITC | item discrimination |
| Alpha if deleted | local redundancy signal |
| EFA primary loading | exploratory alignment |
| EFA secondary loading | overlap/cross-loading |
| CFA standardized loading | confirmatory strength |
| CR / AVE context | construct convergence |
| Semantic redundancy | content duplication |
| Unique facet | what would be lost if deleted |
| Subgroup applicability | cross-major/cross-group coverage |
| Action | retain / monitor / rewrite / delete candidate |
| Rationale | statistics + theory + content |

A deletion candidate should normally have more than one weakness and little unique content contribution.
