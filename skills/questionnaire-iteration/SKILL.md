description: Decide how to revise a questionnaire after pretest results. Use when the user wants to retain, monitor, rewrite, delete, or compare items/versions while balancing psychometric evidence, theory, content coverage, and subgroup applicability.
---

Use this skill after psychometric diagnostics are available.

## Decision principle
No item decision should rely on a single threshold. Every recommendation must combine:
- statistical evidence;
- theoretical role;
- content validity;
- subgroup/cross-context applicability.

## Build an item decision matrix
For each item include:
- item ID and dimension;
- valid N / not-exposed rate;
- mean and SD;
- CITC;
- alpha if deleted;
- EFA primary loading;
- cross-loading/secondary loading;
- CFA standardized loading;
- effect on CR/AVE if relevant;
- semantic redundancy;
- unique content contribution;
- subgroup applicability;
- recommended action.

## Four default actions
1. Retain: theory and evidence are adequate.
2. Retain but monitor: one or two metrics are borderline but the item is theoretically/content-important.
3. Rewrite: weakness may come from ambiguity, double wording, narrow context, or poor response process.
4. Candidate deletion: multiple persistent weaknesses plus low unique content contribution.

## Version comparison
If shortening the scale, compare multiple versions on the same respondents and fixed EFA/CFA split. Compare:
- parallel-analysis factor count;
- EFA recoverability;
- CFA fit;
- alpha/omega;
- CR/AVE;
- HTMT;
- AIC/BIC;
- number of items per dimension;
- content coverage.

Do not select the shortest version simply because it fits best. Reject over-deletion when it collapses important factors or leaves dimensions underrepresented.

Read `references/item-decision-matrix.md` for the recommended structure.

## 多种子版本比较增强（v1.1）

对候选删题版先提供12轮中等情景指标的中位数、最小最大值及达标轮数，再附2轮噪声压力与2轮较高共同性结果。提高中等情景表现却在噪声下崩溃，属于敏感候选；只在较高共同性下“通过”，不构成真实有效的证据。优先以8个开发种子决定候选并锁定版本，4个保留种子用于后续复核，不应再重新优化并声称独立验证。请按 `references/multiseed-decision-worksheet.md` 记录每个删除题项的独特侧面损失，并以研究者的理论/内容审查为最终决策。禁止按单一AVE/CFI指标或最漂亮模拟轮次自动筛选。
