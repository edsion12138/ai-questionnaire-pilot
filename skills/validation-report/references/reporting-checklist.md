# Reporting checklist

Before finalizing, verify:
- data source labeled silicon vs human;
- original N and analysis N both reported;
- missing/not-exposed handling stated;
- EFA extraction and rotation stated;
- parallel-analysis method stated;
- CFA estimator and competing models stated;
- alpha and omega both considered;
- CR/AVE and loading range reported;
- full Fornell-Larcker and HTMT available;
- criterion scale kept separate from new-scale EFA/CFA;
- cross-sectional criterion association not called predictive validity;
- all random seeds recorded;
- fixed split not silently redrawn;
- item renumbering map retained;
- human validation steps clearly marked as pending when not yet performed.
